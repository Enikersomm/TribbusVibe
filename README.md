# 🪐 Tribbu'sVibe — Conectando pessoas de verdade.

O **Tribbu'sVibe** é uma plataforma de rede social antialgoritmo híbrida desenvolvida especificamente para a nova Geração  que resgata o aconchego das comunidades e a interação humana saudável, combinando as melhores ferramentas de comunicação do século 21.

## 📐 Os 3 Pilares Estratégicos

### ⚡ 1. Energia
* **Interface Industrial Cyber-Pop:** Design em alto contraste (Dark Mode absoluto) focado na economia de bateria e conforto visual, utilizando o degradê circular neon de nossa marca oficial.
* **Sincronização Realtime:** Sistema de mensagens instantâneas alimentado pelo **Tribbu's Messenger** utilizando Firebase SDK v10.

### 🧘 2. Equilíbrio
* **Arquitetura Antialgoritmo:** Feed estritamente cronológico. Zero manipulação de dados para retenção viciante de usuários. Valorização extrema da saúde mental e privacidade.
* **Transparência Relacional:** Termômetros clássicos de reputação (*Legal, Confiável e Vibe*) editáveis e rastreáveis na rede.

### 👥 3. Comunidade ("Tribo") — O Principal
* **Fóruns Baseados em Interesses Reais:** Compartilhamento focado em grupos temáticos, removendo a cultura do narcisismo individual de curtidas vazias.
* **Mural de Scraps e Eventos:** Foco absoluto no engajamento comunitário online e na facilitação de encontros na vida real.

---

## 🛠️ Stack Tecnológica
* **Frontend:** HTML5, CSS3 Moderno (Módulos Flexbox/Grid e Variáveis nativas) e React 18 / Tailwind CSS.
* **Backend & Infraestrutura:** Firebase Firestore (Realtime NoSQL Database) e Firebase Authentication.
* **Hospedagem & CI/CD:** Repositório Git (GitHub) acoplado a Deploy automatizado via Netlify / Cloud Run.

## 🚀 Como Subir para o GitHub e Netlify

### 1. No GitHub
1. Crie um repositório no seu GitHub (ex: `tribbus-vibe`).
2. No seu terminal ou exportando pelo menu do AI Studio:
   ```bash
   git init
   git add .
   git commit -m "feat: lancamento oficial Tribbu'sVibe"
   git branch -M main
   git remote add origin https://github.com/SEU-USUARIO/tribbus-vibe.git
   git push -u origin main
   ```

### 2. No Netlify
1. Conecte sua conta do GitHub ao Netlify.
2. Selecione o repositório `tribbus-vibe`.
3. As configurações já estão prontas no arquivo `netlify.toml`:
   - **Build Command:** `npm run build`
   - **Publish directory:** `dist`
4. Clique em **Deploy Site**. Pronto! O Tribbu'sVibe estará no ar com HTTPS e rotas SPA funcionando perfeitamente.
